# Bíblia de Estudo — V2.1.0

## Novidades
- Estatísticas reais de leitura no Perfil.
- Contagem de versículos lidos e capítulos concluídos.
- Registro de dias em que houve leitura.
- Progresso percentual baseado nos 1.189 capítulos da Bíblia.
- Favoritos por versículo persistidos localmente.
- Anotações pessoais por versículo persistidas localmente.
- Insígnias passam a ser calculadas com base no uso real.
- Service Worker atualizado para o cache V2.1.

## Observação
Os dados permanecem locais no aparelho usando localStorage. Nenhum servidor ou conta é necessário.
